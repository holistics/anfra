## Bad AQL
```aql
metric user_count = users | count(users.id);
metric country_rank_by_user_count = rank(order: user_count | desc());

explore {
  dimensions {
    country_code: countries.code,
    country_name: countries.name,
  }
  measures {
    user_count: user_count,
    country_rank: country_rank_by_user_count,
  }
  having {
    country_rank < 11,
  }
  sorts {
    user_count DESC,
  }
}
```

## Why it's bad
* `explore.having` takes a **metric name**. `country_rank` is a measure alias, and a measure alias in `having` is not supported right now.
* Fix: `having { country_rank_by_user_count < 11 }` (example 4), or `filters { country_rank < 11 }` (example 71).

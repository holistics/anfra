  model: ''

## AQL
```aql
metric user_count = users | count(users.id);
metric country_rank_by_user_count = rank(order: user_count | desc());

explore {
  dimensions {
    country_code: countries.code,
    country_name: countries.name,
  }
  measures {
    user_count: user_count,
    country_rank: country_rank_by_user_count,
  }
  filters {
    country_rank < 11,
  }
  sorts {
    user_count DESC,
  }
}
```

## Learning points
* A metric condition can go in `explore.filters` by its **measure alias** (`country_rank`), as an alternative to `having { country_rank_by_user_count < 11 }` (example 4). Both give the same result.
* The metric must be in `explore.measures` to have an alias. To filter on a metric without showing it, use `having` by metric name.
